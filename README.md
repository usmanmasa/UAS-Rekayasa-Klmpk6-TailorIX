# Tugas User Persona & User Journey

Folder ini berisi dokumen untuk tugas testing yang akan diunggah ke project kanban GitHub.

## Isi folder

- `user_persona_journey.md` - Profil pengguna fiktif (Pelanggan & Penjahit) dan alur pengguna lengkap.

## Tujuan

Membantu tim memahami siapa target pengguna aplikasi, apa kebutuhannya, dan bagaimana alur mereka saat menggunakan aplikasi.

## Cara pakai

1. Buka `user_persona_journey.md`.
2. Gunakan profil dan alur pengguna untuk membuat test case, skenario testing, atau dokumentasi produk.
3. Upload folder ini ke GitHub sebagai bagian dari tugas Kanban.
