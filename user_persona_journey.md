# User Persona & User Journey

## 1. User Persona

### A. Pelanggan

- Nama: Siti Maharani
- Umur: 28 tahun
- Pekerjaan: Karyawan swasta
- Lokasi: Jakarta Selatan
- Preferensi: Belanja online, ingin pakaian custom yang rapi dan cepat jadi

#### Tujuan
- Memesan pakaian custom secara mudah dari smartphone.
- Melihat katalog bahan dan model.
- Mendapatkan estimasi harga dan waktu pengerjaan.

#### Frustrasi
- Tidak tahu cara mengukur badan dengan benar.
- Sulit berkomunikasi dengan penjahit bila hanya lewat chat biasa.
- Ingin proses pembayaran dan tracking order yang jelas.

#### Kebutuhan
- Panduan upload foto ukuran atau pengukuran yang jelas.
- Fitur chat atau notifikasi progress.
- Metode pembayaran yang aman.

### B. Penjahit

- Nama: Budi Santoso
- Umur: 42 tahun
- Pekerjaan: Penjahit rumahan / owner workshop kecil
- Lokasi: Bandung
- Preferensi: Memiliki order tetap, butuh pengaturan jadwal, dan ingin pesanan jelas.

#### Tujuan
- Menerima pesanan dengan spesifikasi lengkap.
- Mengelola status pengerjaan order.
- Dapat memberi estimasi harga dan waktu pengerjaan yang valid.

#### Frustrasi
- Order sering tidak lengkap detail ukurannya.
- Kesulitan mengatur prioritas order.
- Sulit berkomunikasi dengan pelanggan bila data pesanan tidak terstruktur.

#### Kebutuhan
- Order masuk dengan detail model, ukuran, bahan, dan catatan khusus.
- Fitur notifikasi ketika ada order baru atau perubahan.
- Dashboard sederhana untuk melihat status pesanan.

## 2. User Journey

### A. Alur Pelanggan

1. Membuka aplikasi.
2. Melihat daftar layanan / katalog model.
3. Memilih jenis pakaian yang ingin dipesan.
4. Mengisi detail ukuran dan preferensi bahan.
5. Mengunggah foto referensi atau gambar desain.
6. Mengirim permintaan order.
7. Menerima estimasi harga dan waktu pengerjaan.
8. Melakukan pembayaran atau setujui order.
9. Menerima notifikasi progres pengerjaan.
10. Mengonfirmasi penerimaan barang setelah selesai.

#### Titik Interaksi Penting
- Tampilan halaman utama yang jelas.
- Form input ukuran yang mudah diisi.
- Fitur upload file/foto.
- Notifikasi status.

### B. Alur Penjahit

1. Login ke aplikasi.
2. Melihat notifikasi order baru.
3. Membuka detail order pelanggan.
4. Memeriksa ukuran, bahan, dan catatan khusus.
5. Memberikan estimasi harga dan waktu.
6. Mengubah status order menjadi "Diproses".
7. Mengupdate progress jika dibutuhkan.
8. Menandai order selesai ketika pakaian sudah jadi.
9. Mengirimkan informasi pengambilan atau pengiriman ke pelanggan.

#### Titik Interaksi Penting
- Dashboard order yang ringkas.
- Detail order lengkap dan mudah dibaca.
- Tombol aksi untuk mengubah status order.
- Riwayat order untuk referensi.
